# Dashboard MVP simplification

The dashboard must focus on four daily tasks: overview, products, orders, and essential settings.

- Remove Messages, Returns, and Customers from dashboard navigation.
- Keep Products as a direct link without a submenu.
- Keep only General, Payments, Shipping, and Security in Settings.
- Orders must explicitly show loading, failure with retry, and empty states instead of silently swallowing API failures.
- Customer support remains on the storefront chatbot and escalates to WhatsApp; there is no internal inbox in the MVP dashboard.
- Preserve existing order-management and settings capabilities behind the retained screens.
